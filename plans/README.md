## Findings considered and rejected / settled

- **Public + unauth Traefik exposure, `docker.sock` on agent-core** — known, tracked
  (SECURITY-AUDIT-2026-07-02 §4.1/§4.2, remediation tracker; ECOSYSTEM §2.5.2). The
  Traefik ClientIP/forward-auth split and socket-proxy live in `home-server`, out of
  this repo. Plan 001 adds app-level auth as defense-in-depth. The audit notes much of
  this "dies with the agent-gateway→persona-gateway migration".
- **Shared Mattermost bot tokens** (MATTERMOST_BOT_TAYNE/MONITOR/TRADING) — the tokens
  themselves are env-injected (not committed here); the shared-token hygiene issue is
  H7 in the security audit (tracked, rotation ⚙️ pending), not a code finding in this repo.
- **`agent-gateway`/`ai-gateway` name collision** — real, but resolution is part of the
  rebuild (plan 002 Q4), not a standalone fix.
- **Thin test coverage (5 files)** — raised as a requirement inside plans 001/002/003
  (each adds tests) rather than a standalone "write tests" plan.
